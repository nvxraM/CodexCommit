# Screenshots

These screenshots show PyCharm 2026.2.3 with CodexCommit 1.1.2 in an isolated test profile.
The project contains only sample files.

- `generate-button.png` shows the real Commit toolbar and the Codex button tooltip.
- `review-request.png` shows the real request review dialog with a sample patch.
- `review-draft.png` shows the real draft review dialog with a supplied sample message.

The real toolbar action opens the request review dialog.
A local test harness opens the draft dialog with a sample message.
It does not call the Codex service.
The sample draft is an example, not a recorded model response.
These images do not establish real-account or complete native workflow acceptance.
