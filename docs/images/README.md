# Screenshots

These screenshots show PyCharm 2026.2.3 with CodexCommit 1.1.3 in an isolated test profile.
They use twice the original pixel density and only sample data.

- `generate-button.png` shows the real Commit toolbar and button tooltip at 1100 × 232 pixels.
- `review-request.png` shows the real request review dialog at 1778 × 1234 pixels.
- `review-draft.png` shows the real draft review dialog at 1770 × 1234 pixels.

The request and draft use a simple greeting example.
A local test harness opens both review dialogs with supplied sample text.
It does not call the Codex service. The sample draft is not a recorded model response.
The request shows a sample model ID. Normal operation detects the local CLI model automatically.
The README places each review image below its instruction. Select an image to view it at full resolution.
These images do not establish real-account or complete native workflow acceptance.
