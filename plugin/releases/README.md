# Candidate ZIP

This directory contains the CodexCommit 1.1.8 candidate ZIP.

- Spin the outer cube during generation.
- Animate README wordmarks and the button picture.
- Refresh the usage demo. Keep plugin logos and the Overview picture static.

One click fills the commit message field with a short draft.
Workspace XML contents stay out of generation.
Read the [user guide](../docs/USAGE.md) for requirements and limits.
Read the [verification record](../docs/VERIFICATION.md) and [security audit](../docs/SECURITY_AUDIT.md) for passed checks and incomplete tests.

The ZIP does not include an account, credentials, Git, or the Codex CLI.
Source generation needs native Codex CLI 0.160.1 and a personal account without organization policy.
Read the main [README](../../README.md) for the other requirements and installation steps.

The SHA-256 value is in `SHA256SUMS`.
This value identifies the checked bytes.
It does not prove that the software has no risk.
